One cat joke, one line. It's about my mug, which has been pushed off the kitchen table three mornings running now, slowly, while eye contact was maintained. I have moved the mug. She has found the mug. The program just writes the joke to the output file after checking it fits in 200 characters, nothing fancier than that.

## Run it

```sh
node --experimental-strip-types main.ts
```
